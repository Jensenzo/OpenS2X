# Code of conduct

This project is a place to talk about a game and the program that runs it.
Everyone who takes part, in issues, pull requests and discussions, is
expected to:

- be respectful and patient, especially with people new to the project;
- discuss the work, not the person;
- keep to the subject and assume good intent;
- accept that the maintainer decides what goes into the project.

Not accepted: harassment, insults, personal attacks, discriminatory language,
sharing someone's private information, and posting game files or decompiled
code (see [`CONTRIBUTING.md`](CONTRIBUTING.md)).

The maintainer may edit or remove comments, close issues and block accounts
that break these rules. To report a problem with someone's conduct, use
GitHub's **Report content** on the comment, or open an issue asking the
maintainer to contact you privately.
