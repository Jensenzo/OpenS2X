# Specs

Behavioral specifications of The Settlers II: 10th Anniversary, written in our own
words. These are the only input the implementation side uses.

- Copy `_TEMPLATE.md` to `<AREA>-<topic>.md` (for example `TRN-carrier-priority.md`).
- Area codes: `FMT` file formats, `MAP` map and terrain, `TRN` roads and transport,
  `ECO` production and economy, `MIL` military, `AI` computer players, `UI` interface.
- Questions not yet answered live in `OPEN_QUESTIONS.md`.
